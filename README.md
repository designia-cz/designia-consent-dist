# Designia Consent – distribuce

Sestavené soubory cookie lišty s Google Consent Mode v2. Lišta se nasazuje přes GTM šablonu „Designia Consent“, která skript načítá z jsDelivr:

```
https://cdn.jsdelivr.net/gh/designia-cz/designia-consent-dist@1.0.0/designia-consent.min.js
```

Každá verze má vlastní git tag. Weby používají vždy konkrétní verzi, nikdy `@latest`.
